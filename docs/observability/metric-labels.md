# Metric labels

Generated by `python3 -I scripts/metrics_catalog.py`; do not edit by hand.

Every label key a family carries, what it means, and the families that carry it. Label values that identify a worker are its registration URL, so per-worker series come and go with the fleet (the gateway retires a worker's series when the worker is removed). Client-controlled values (`model`, MCP `tool`) are bounded: past the cap they collapse to `other`.
